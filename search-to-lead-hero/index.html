From a search to a new enquiry, in one loop.

A hero animation for a website development company: a buyer searches, finds the business, opens the site and sends an enquiry. The city in the search changes each loop, because the same journey happens in New York, London, Dubai, Toronto, Sydney and Chennai.

  • Pure HTML, CSS and JS. No libraries.
  • Respects reduced motion. It shows the final frame instead.
  • One timeline. Every step is a class on the stage.
